折腾了一下午，这个小摊子总算支起来了。

## 为什么叫这个名字

「篝火边，冷饮摊」——一边是烧得正旺的火，一边是冰镇过的饮料。把一个热的和一个凉的东西摆在一起，本身就有点好笑，所以我拿它当了站名。

顺带一提，这个站的主题色取自头像的那抹蓝，再拿红色点了一下作点缀。你可以在右下角的调色盘里改成自己喜欢的颜色。

## 这里会写什么

大概没什么固定的主题。计划是这几类：

- **折腾记录**：装了什么、坏了什么、怎么修好的
- **技术笔记**：踩过的坑，趁还记得赶紧写下来
- **随便写写**：想说什么说什么

更新频率不敢承诺，毕竟「偶尔更新」才是个人博客的常态。

## 这个站是怎么搭的

用的是 [Astro](https://astro.build) 加 [Fuwari](https://github.com/saicaca/fuwari) 主题，托管在 GitHub Pages 上，构建和部署都交给 GitHub Actions。没有服务器，也就不存在续费的问题。

主题本身支持的东西挺多：代码高亮、数学公式、折叠块、GitHub 仓库卡片之类的。以后写到需要的时候再慢慢用。

## 最后

如果你是从 B 站过来的，欢迎到处逛逛。文章下面有评论区，想说点什么都可以——虽然现在还没什么人。

那就先这样，下次见。
